DecodeLabs – Project 2

Exploratory Data Analysis (EDA) – README

1. Project Overview

This project performs Exploratory Data Analysis (EDA) on a synthetic retail sales dataset. The analysis is used to understand sales patterns, trends, distributions, outliers, and relationships between numerical variables.

2. Project Goal

The main goal of this project is to analyze the sales data and identify useful patterns, trends, and business insights.

3. Dataset

- Number of Orders: 120
- Cities: 6 Indian cities
- Categories: 3 product categories
- Time Period: 12 months
- Main Variables: Unit Price, Quantity, Discount, Sales, Profit Margin, Profit, City, Category, and Order Date
- Sales Calculation: Sales is calculated using Unit Price, Quantity, and Discount.

4. Analysis Included

Basic Statistics:
Count, Mean, Median, Minimum, Maximum, and Standard Deviation.

Outlier Analysis:
Potential outliers are identified for investigation.
Sales = Unit Price × Quantity × (1 − Discount% / 100)
Profit = Sales × Profit Margin.
Outliers are flagged and are not automatically deleted.

Monthly Trend Analysis:
Monthly sales and profit are summarized to understand changes and trends over the 12-month period.

Category Analysis:
Sales and profit are analyzed category-wise to identify better-performing product categories.

City Analysis:
Sales and profit are summarized city-wise to compare performance across the six cities.

Correlation Analysis:
Pearson correlation is used to study relationships between numerical variables.

Key Insights & Recommendations:
Important findings and actionable recommendations are summarized based on the analysis.
